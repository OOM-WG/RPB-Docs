## 各个机型教程

下载 ROOT 工具请按照各机型指引操作

<Callout type='warn'>
下载 ROOT 工具时需要注意**对应机型**并且**对应系统版本号**！

如果当前设备有 `init_boot` 分区，那么可以使用**该机型**的 `init_boot` 通用 ROOT 工具，
但是如果当前设备只有 `boot` 分区，则必须**区分版本号**！

如果不知道什么是 `init_boot`/`boot`，除非明确说明了可以使用**该机型**的 `init_boot` 通用 ROOT 工具，那不然一定要**区分版本号**！

如果不知道如何查看系统版本号，请执行以下操作:

1. 进入系统的 `设置` 软件
2. 进入 `关于本机` 页面的 `版本信息` 子页面，`版本号` 一栏即为当前设备的系统版本号

</Callout>
